# Kairoz

Kairoz 是数据闭环平台（DCL）中**数据采集平台**的可运行产品原型。业务团队定义要从车辆采集哪些文件、在什么条件下采集，经 DCL 工程接入、仿真与实车验证、集成合并、正式发布后，以配置 OTA 下发到车辆，并对每个采集事件保留完整的配置追溯。

这是一个**产品原型**，而不是生产系统：全部业务状态与规则运行在浏览器里并保存在本地，车辆、仿真器、OTA Agent 与云端处理由内置的**车辆模拟器**模拟。原型可以完整走通各角色协作的工作流，没有服务器、数据库或部署。

需求来源是原型 v0.13（`Data_Acquisition_Platform_Data_Query_20261018.zip`）的设计文档；原型代码只作行为参考。

## 运行

需要 Node.js 24。

```bash
npm install
```

```bash
npm run dev
```

打开 `http://127.0.0.1:5173`，选择一个账号进入。界面支持中文 / English 切换（右上角）。

构建静态版本（`apps/prototype/dist`，相对路径，可放到任意静态 HTTP 托管；浏览器不允许从本地文件直接打开模块脚本，本地查看请用下面的预览命令）：

```bash
npm run build
```

```bash
npm run preview -w @kairoz/prototype
```

## 使用

- **选择账号**：不校验密码；每个账号的权限完全由它的授权决定。登录页按角色分组，可搜索，并显示每个账号会进入的工作区（本浏览器里上次用过的，否则是待办最多的）。
- **原型工具**（右上角）：车辆模拟器、PLM（模拟）与 TSP（模拟）这两个外部系统、场景手册、重置为演示数据或干净安装、导出 / 导入完整状态 JSON（导入可选文件，替换前先显示摘要）。多人协作演练时，在一个浏览器里切换账号，或用导出 / 导入交接状态。
- **场景手册**：按步骤列出每条协作流程应由哪个账号执行、预期结果是什么，并可一键切换到该账号。平台本身不会替你执行步骤。
- **流程验收（逐幕）**：22 份剧本（设计文档的从零启动、首次 OTA、数据使用，以及按后续设计补写的 19 份）与 24 个反向用例，逐幕操作并记录结果与证据，可导出 JSON / CSV。

## 验收

```bash
npm run acceptance
```

在引擎层逐幕重放 22 份剧本（设计文档的三份，加按后续设计补写的 19 份）与 24 个反向用例，每次重新执行（最近一次：233 幕通过、0 失败、3 幕不适用于浏览器原型），结果写入 [docs/acceptance/RESULTS.md](docs/acceptance/RESULTS.md)。浏览器中逐幕操作的记录见 [docs/acceptance/BROWSER-RUN.md](docs/acceptance/BROWSER-RUN.md)。

## 目录

```
apps/prototype/
  src/domain/   纯业务规则：授权、触发表达式、数据身份、配置差异与三方合并、审核签名
  src/engine/   原型平台引擎：状态、操作（每次操作一个事务）、演示数据、车辆模拟器
  src/app/      浏览器接线：持久化、会话、路由、外壳
  src/pages/    各角色页面
  src/i18n/     中英文
  test/         引擎与规则测试
  acceptance/   剧本的引擎层逐幕重放（剧本内容在 src/acceptance）
docs/           架构说明（architecture.md）、验收记录（acceptance/）、审查与改进记录（audit/）
```
